# Mianmian-s-Portrait-Cover-Design

棉棉的带人像封面制作 Skill。它可以根据用户照片和视频主题生成醒目人像封面，适用于 YouTube、小红书、抖音、视频号及其他内容平台。

## 功能特点

- 支持五种封面比例：
  - 16:9（YouTube）
  - 4:3（经典）
  - 3:4（小红书）
  - 9:16（抖音、视频号竖屏）
  - 1:1（方形）
- 引导用户上传自己的清晰照片。
- 根据视频主题、简短描述或口播内容，自动提炼醒目的主标题和副标题。
- 对人物进行自然美颜：
  - 美白并均匀肤色
  - 自然磨皮，同时保留真实皮肤质感
  - 去除额头、鼻子和面颊油光
  - 调整高颅顶
  - 增加头发蓬松感
- 保留人物身份和可识别的五官特征。
- 可以根据内容重新设计人物姿态，例如手持麦克风、指向标题、展示手机或产品。
- 使用大号黑体字、白色描边、薄荷绿与薰衣草紫错位阴影，生成醒目的创作者封面。
- 自动检查中文文字、图片比例、手部结构、手机边缘和人物美颜效果。

## 使用流程

1. Skill 首先让用户选择封面比例。
2. 用户上传一张清晰的个人照片。
3. Skill 询问视频主题，或让用户粘贴简短描述、提纲、口播内容。
4. Skill 提炼主标题和副标题，并请用户确认。
5. 确认后完成人物美颜、姿态设计和封面合成。
6. 检查尺寸、文字、人物身份及画面质量后交付成品。

## 示例

用户提供的视频描述：

> 我给自己的 Agent 注册了邮箱，它现在可以帮我发送邮件，以后还可以帮我清理垃圾邮件。

Skill 可以提炼为：

- 主标题：`我给 Agent 注册了邮箱！`
- 副标题：`能发邮件，还能清理垃圾邮件`

## 仓库结构

```text
.
├── SKILL.md
├── agents/
│   └── openai.yaml
├── assets/
│   └── references/
│       ├── reference-3x4.png
│       └── reference-4x3.png

```

`SKILL.md` 定义完整交互与生成流程，`style-guide.md` 记录视觉规范，`assets/references/` 中的图片仅作为构图和风格参考。

## 隐私说明

用户上传的照片仅用于当次封面制作，不应被打包、公开发布或复用为 Skill 素材，除非获得用户明确许可。
